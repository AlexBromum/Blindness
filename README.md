# Blindness mod for Cataclysm: Bright Nights

Мод, добавляющий немного вещей для персонажей со слепотой в Cataclysm BN.

A mod that adds useful tools and items for blind characters in Cataclysm BN.

## Предметы

- **Белая трость** — длинная трость, которая позволяет ориентироваться в пространстве чуть лучше. Легко скрафтить, маленький радиус действия, нужно держать в руках.
- **Ультразвуковой эхлокатор** — механическая пищалка, которая при активации ненадолго открывает пространство вокруг. Немного шумная, работает недолго, зато не нужны батарейки.
- **Аудиопланшет** — высокотехнологичный планшет, сканирует окружение в небольшом радиусе, сканирует книги в инвентаре, и озвучивает это вслух. Шумит, требует батареек, и его нужно держать в руках. Позволяет читать книги, но не крафтить.

## Features

- **Blind Cane** — a simple tool that helps blind characters orient in space
- **Ultrasonic Echo-locator** — a rechargeable device that reveals nearby surroundings
- **Audio Tablet PC** — reads books aloud and describes nearby environment

## Установка

1. Загрузите последнюю версию со страницы [Релизы](https://github.com/AlexBromum/Blindness/releases)
2. Распакуйте архив в папку "\userdata\mods"
3. Включите мод при создании мира.

## Installation

1. Download the latest release from the [Releases page](https://github.com/AlexBromum/Blindness/releases)
2. Extract the archive to your `\userdata\mods` folder
3. Enable the mod in the game's mod manager
